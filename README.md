# حاجي بزنس — Haji Business

منصة وكيل ذكاء اصطناعي قابلة للتطوير لإدارة المهام، الذاكرة، الأوامر، الصلاحيات والإشعارات، مع وحدات مستقلة للأعمال والتداول والصلاة والرياضة والتواصل.

## النواة
- Memory: ذاكرة الوكيل وسياق المستخدم.
- Commands: فهم وتنفيذ الأوامر.
- Tasks: إنشاء ومتابعة المهام.
- Permissions: صلاحيات واضحة وموافقة صريحة قبل الإجراءات الحساسة.
- Notifications: تنبيهات ومتابعة النتائج.

## الوحدات المخطط لها
- Prayer
- Sports
- Tasks
- Business
- شركة المشارق الأولى
- Trading
- Communication

## مبدأ الأمان
أي إجراء مالي أو التزام حساس يحتاج موافقة صريحة من المستخدم قبل التنفيذ.

## الحالة
المرحلة الأولى: تأسيس النواة والبنية Modular تمهيداً لبناء التطبيق الفعلي وتوصيل الوحدات والخدمات.
