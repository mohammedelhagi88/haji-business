# Trading Module

وحدة تحليل مستقلة داخل حاجي بزنس.

## المؤشرات الحالية
- SMA / EMA / WMA
- RSI
- Bollinger Bands
- ATR
- OBV
- VWAP

## التوسعة القادمة
- MACD و Stochastic
- ADX و Ichimoku و Parabolic SAR
- CCI و MFI و Williams %R و ROC
- Fibonacci و Pivot Points
- محرك تجميع الإشارات وقياس الثقة والمخاطر
- تحليل متعدد الأطر الزمنية

> هذه الوحدة للتحليل فقط في المرحلة الحالية. لا يوجد تنفيذ تلقائي للصفقات.
> أي أمر مالي لاحقاً يمر عبر نظام الموافقة الصريحة في النواة.
