# Communication Module

وحدة التواصل في حاجي AI لإدارة نوايا الاتصال والرسائل والتواصل الاجتماعي.

## القنوات

- `CALL` — الاتصال بجهة اتصال.
- `SMS` — رسالة نصية.
- `SOCIAL` — رسالة عبر مزود اجتماعي يدعم التكامل.

## الأمان

- تجهيز الرسالة مسموح بدون إرسال.
- الاتصال والإرسال يحتاجان `approved=True` في الطلب.
- لا يوجد إرسال فعلي بدون Adapter مربوط بمزود محدد.
- لا توجد صلاحية نشر جماعي أو إرسال عشوائي ضمن هذه الطبقة.

الطبقة الحالية هي أساس قابل للتوسعة. يمكن لاحقًا إضافة Adapters للهاتف وSMS والمنصات الاجتماعية حسب الصلاحيات وواجهات كل خدمة.
