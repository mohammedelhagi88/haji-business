# Core

النواة المشتركة لحاجي بزنس.

## مكونات النواة

- `memory/` — إدارة الذاكرة والسياق.
- `commands/` — استقبال الأوامر وتوجيهها.
- `tasks/` — دورة حياة المهام.
- `permissions/` — فحص الصلاحيات والموافقات.
- `notifications/` — التنبيهات والنتائج.

هذه المجلدات تمثل الحدود الأولية للنواة، وسيتم تحويلها إلى مكونات تنفيذية مع تثبيت واجهاتها البرمجية.
